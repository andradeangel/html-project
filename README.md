# Proyecto HTML - Página Web Pura

Una página web desarrollada **exclusivamente con HTML** para demostrar las capacidades y posibilidades del lenguaje de etiquetas HTML como base fundamental en el desarrollo web.

## 📋 Descripción

Este proyecto tiene como objetivo mostrar qué se puede lograr utilizando **únicamente HTML**, sin depender de CSS, JavaScript u otros lenguajes complementarios. Es una excelente herramienta educativa para comprender la estructura y semántica del HTML.

## 🎯 Objetivos

- Demostrar los fundamentos del lenguaje HTML
- Mostrar la importancia de la estructura semántica web
- Servir como referencia de buenas prácticas en HTML
- Educar sobre las capacidades básicas del desarrollo web

## 📁 Estructura del Proyecto

```
html-project/
├── README.md
├── index.html
└── [otros archivos HTML]
```

## 💻 Tecnologías Utilizadas

- **HTML5** - Lenguaje de etiquetas para estructuración de contenido

## 🚀 Cómo Usar

1. Clona el repositorio:
```bash
git clone https://github.com/andradeangel/html-project.git
```

2. Abre el archivo `index.html` en tu navegador web favorito

3. Explora la página y examina el código fuente para entender la estructura HTML

## 📚 Contenido Principal

Este proyecto incluye ejemplos de:

- Estructura básica de documentos HTML
- Etiquetas semánticas
- Formularios HTML
- Listas y tablas
- Hipervínculos y navegación
- Elementos multimedia
- Mejor práctica en accesibilidad web

## 🎓 Aprendizaje

Este proyecto es ideal para:

- Estudiantes que inician su camino en desarrollo web
- Personas que desean fortalecer sus conocimientos en HTML
- Desarrolladores que buscan refrescar conceptos fundamentales

## 📝 Notas

Recuerda que aunque HTML es el fundamento, en proyectos reales se complementa con:
- **CSS** para estilos y diseño visual
- **JavaScript** para interactividad y lógica dinámica
